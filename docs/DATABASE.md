# Database

Oracle is the system of record. Flyway owns schema creation.

## Design rules
- UUID/string IDs are generated by the application unless Oracle generation is explicitly chosen.
- Every child table has an explicit FK.
- Add indexes for FK columns and real query predicates.
- Use NOT NULL, CHECK and UNIQUE constraints for invariants that belong in the database.
- Keep timestamps consistent.
- Do not duplicate the same business fact across tables without a defined synchronization rule.

## Rebuild policy
The current rebuild starts from a fresh schema baseline. The old address migration/backfill chain is retired.
Do not add compatibility migrations for the discarded schema.
